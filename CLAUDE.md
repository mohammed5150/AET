# CLAUDE.md

Repository rules for coding agents are in AGENTS.md; the knowledge base index
and lessons are loaded below so every session starts with them.

@AGENTS.md
@knowledge-base/INDEX.md

## Every session

1. **Start:** read the newest entries in `knowledge-base/WORKLOG.md` and open
   the lesson notes the index lists for the area you are about to change.
2. **Work:** branch from `main` (see CONTRIBUTING). Run `scripts/check.sh`
   before each commit.
3. **Finish:** follow `knowledge-base/topics/orientation/session-protocol.md`:
   add a WORKLOG entry, record any new lesson as a note, update the repo map
   if modules moved, and re-run `scripts/check.sh`.
